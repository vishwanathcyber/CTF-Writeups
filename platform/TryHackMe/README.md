# TryHackMe

## Overview

This directory contains writeups for TryHackMe challenges.

## Challenge Categories

- Web Exploitation
- Cryptography
- Binary Exploitation
- Reverse Engineering
- Digital Forensics
- General Skills
- OSINT

## Repository Structure

Each challenge should contain:

- Challenge Description
- Objective
- Enumeration
- Analysis
- Exploitation
- Flag
- Lessons Learned
- References

## Goal

Document every challenge in a structured and reproducible manner while explaining the reasoning behind each solution.
